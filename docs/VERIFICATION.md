# 0.2.0 로컬 검증

검증일: 2026-09-20. 운영 배포/실서비스 DB 변경 없이 로컬에서 확인했습니다.

## 변경 전 관찰

기존 `ot-hub-preview.html`: 713,671 bytes. 인라인 이미지, 데이터, CSS, JS가 한 파일에 포함되어 캐시 단위를 분리하기 어려웠습니다. 각 메뉴 클릭마다 feed의 innerHTML을 새로 생성했으며 일부 데스크톱 메뉴는 하단 탭이 없을 때 선택 상태 동기화가 생략되었습니다. 검색 초기화는 없는 searchInput ID를 참조했고 검색어를 HTML에 직접 삽입했습니다.

## 변경 후 검증

- 새 `index.html`은 약 4KB. 콘텐츠 데이터 약 4KB. 스타일·스크립트·이미지는 별도 요청이며, 전체 전송량이 4KB라는 의미는 아닙니다.
- 기존 공개 콘텐츠 16개의 로컬 파일과 썸네일 존재 확인.
- 메뉴별 DOM 재사용, 선택 상태, 뒤로 가기와 직접 링크, 기존 주소의 새 화면 이동.
- 북마크 저장/해제/새로고침 유지 및 캐시 화면 사이 상태 일치.
- 최근 이용 기록, 기존 훈련 페이지 새 탭 열기.
- 검색어와 댓글 HTML 이스케이프, 검색 상태의 메뉴 전환 시 초기화.
- 1440px 데스크톱과 390px 모바일 스크린샷 확인, 가로 넘침 검사, 모바일 메뉴 이동 시 맨 위로 이동.
- 좋아요·댓글 창, 댓글 표시/등록과 로그인 필요 상태를 위한 연결 구현. 브라우저 테스트는 가짜 응답으로 실행하며 운영 댓글 DB에는 쓰지 않음.
- 통계 동의 전 전송 없음, 선택한 필드만 전송, 동의 철회 시 대기 이벤트 삭제.
- 관리자 화면의 권한 거부 / 마이그레이션 미적용 / 실제 0건 상태 분리.
- PostgreSQL 엔진(PGlite)에서 마이그레이션 재적용, 익명 이벤트 입력, 중복 제거, 유효성 검증, 원시 테이블 조회 거부, 일반 회원 집계 거부, 관리자 셀프 등록 거부, 관리자 집계/이동 경로, 90일 삭제 확인.

최종 측정은 `test-results/navigation.json`, 화면은 `test-results/*.png`에 생성합니다. 초기 로컬 검사에서 메뉴 전환 시작부터 두 번째 화면 프레임까지 33~61ms였습니다. 이는 실사용 INP나 기존 버전 대비 속도 배수를 나타내지 않습니다. 테스트 중 외부 서버 요청은 차단/모킹하므로 인증 서버 속도와 운영망 지연을 포함하지 않습니다.

## 운영에서 추가 확인할 항목

실제 Supabase Auth 메일 로그인/리디렉션, PostgREST 권한, 기존 좋아요/댓글 스키마 호환, Vercel 헤더/캐시, 실기기 훈련의 카메라·오디오·터치, pg_cron 실행, 공개 수집 API 제한, 운영 비용 및 실제 사용자 성능은 `OPERATIONS.md`에 따라 출시 전에 확인해야 합니다.
